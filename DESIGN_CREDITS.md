# Design research / credits

This remix is an original design for KAYJOU. It uses historical early-web conventions
as references rather than copying any specific page or artwork.

## References consulted

1. Personal Homepages (the cultural form), RIP — overview of Geocities/Angelfire-era
   personal pages, animated GIFs, hit counters, under-construction banners, tiled
   backgrounds and guestbooks.
   https://rip.so/personal-homepages.html

2. Vernacular Web, NameThatUI — examples and defining signals of amateur personal-web
   design: tiled textures, animated GIF ornaments, badges/counters, guestbooks and
   intentionally personal decoration.
   https://namethatui.com/styles/vernacular-web

3. Web Design Museum — historical galleries covering 2000–2003 websites.
   https://www.webdesignmuseum.org/gallery/year-2000

4. NC State University Libraries, Hall of GIFs — archived GeoCities GIF culture and
   its role as a defining early-web visual element.
   https://www.lib.ncsu.edu/projects/hall-gifs

5. Guestbook Surfing, archived GeoCities page — example of button/link culture and
   early personal-site graphics/code practices.
   https://www.geocities.ws/TimesSquare/Arcade/1999/guestsurf.html

6. anlucas.neocities.org — modern recreation inspired by late Web 1.0 / early-2000s
   personal sites, including animated GIFs, small buttons and colorful graphics.
   https://anlucas.neocities.org/AboutthisSite

## Palette

#0A0908 — near-black
#49111C — burgundy
#F2F4F3 — off-white

The palette was supplied by KAYJOU. The visual system deliberately avoids the
generic cyan/magenta Y2K palette and instead treats Y2K as a layout/graphic language:
small web buttons, animated ornaments, rules, metadata, compact type and personal-page
energy.
