# Install

1. Open your profile repository:
   https://github.com/Real-Kayjou/KAYJOU
2. Replace its current README.md with this one.
3. Upload the whole `assets` folder.
4. Commit the changes.
5. Wait a few seconds and refresh your GitHub profile.

The README is intentionally image-led. GitHub supports images/GIFs in profile
README content; the design therefore uses hosted repository assets instead of
JavaScript or a custom website shell.
