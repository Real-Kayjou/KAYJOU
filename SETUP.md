# KAYJOU Y2K GitHub Profile Pack

## Files
- `README.md` — profile README template.
- `assets/under-construction.gif` — animated early-web construction badge.
- `assets/spinning-cd.gif` — animated CD decoration.
- `assets/system-status.gif` — blinking system-status badge.

## Install
1. Create/use the public GitHub repository whose name exactly matches your GitHub username.
2. Put `README.md` in the repository root.
3. Upload the `assets` folder.
4. Replace placeholder links/email and project descriptions with your real ones.
5. Preview the README, then commit.

GitHub profile READMEs support images and GIFs through GitHub-flavored Markdown.
